# 비온다? × 날씨봇 — 관심지역 기상·도로살얼음 상시 모니터 (광주대구선 14번)

최대 **8개 관심지역**의 **비·눈 예상 시작 및 종료 시각(3·6·12시간 전망)**, **기상청 고속도로 도로기상관측망(광주대구선 14번 노선) 실측 광학 노면온도(`TR1`)·노면상태(`SFS`)**, **도로 살얼음 및 3단계 제설(살포기 예열 → 사전 살포 → 본 제설)·수방 의사결정**, **기상특보 전종 우선순위 배지 및 발효·해제예정 툴팁**, **1:1 정방형(1080×1080) 브리핑 JPG 공유**를 하나로 통합한 도로관리·생활기상 웹서비스입니다.

## 2. 핵심 제공 기능

1. **비·눈 시작 및 종료 시각 추정 (`비온다?` 핵심 엔진)**
   - 기상청 **초단기실황(`getUltraSrtNcst`) + 초단기예보(`getUltraSrtFcst`) + 단기예보(`getVilageFcst`)** 12시간 시계열을 병합하여 **비·눈 시작 예상 시각**과 **연속 2시간 무강수 예보 기준 종료 추정 시각**을 카드와 상세 화면에 직관적으로 표시합니다.
2. **기상청 고속도로 도로기상관측 API (`road_stn_obs.php?mode=2&var=14`) 실측 연동**
   - 무안광주대구선(`var=14`) 20개 도로기상관측소(거점·기본·목표결빙·목표안개)의 실시간 **광학 노면온도(`TR1`)**, **노면상태(`SFS`: 건조/습윤/수막/적설/결빙)**, **기온(`TA`)**, **습도(`HM`)**, **일강수(`RN_DAY`)**, **적설(`SD`)**, **시정(`VS`)**, **풍속(`WS1`/`WS_INS`)**을 자동 매칭합니다.
3. **모바일 1화면(2열×4행 8개 지역) 고밀도 UI & 위험 등급별 테두리 강조**
   - 모바일 세로 한 화면에서 스크롤 없이 8개 지역을 한눈에 감시할 수 있도록 불필요한 무신호 문구와 중복 기준 시각을 제거했습니다.
   - 주의 단계(주황 테두리 `#e08b00`), 경고/위험 단계(적색 테두리 `#d9381e`)로 위험 카드를 즉각 식별합니다.
4. **기상특보 전종 확장 · 우선순위 배지(`[대표특보 외 N개]`) · 발효/해제예정 툴팁**
   - 대설·호우·태풍·한파·강풍·안개·풍랑·건조·폭염 등 전종 특보를 파싱하여 도로 안전 우선순위(`경보 > 주의보 > 예비특보`, `태풍/대설/호우 > 한파/강풍/안개`)로 정렬하고, 마우스 오버(PC) 또는 터치(모바일) 시 **발효 시각 및 해제 예정 시각** 팝오버 툴팁을 표시합니다.
5. **도로관리청 실무 의사결정 지원 (3단계 제설 역산 타임라인 · 수방 · 교량 횡풍)**
   - **결빙·강설 3시간 전**: `🔑 [제설차 시동·살포기 예열]` (유압 살포기 예열)
   - **결빙·강설 1~2시간 전**: `🚜 [사전 제설(예비살포) 권장]` (습염 사전 살포 출동)
   - **강설 1.0 cm/h 이상 / -6°C 이하**: `🚨 [본 제설 준비]` 및 `⚠️ [저온 결빙 주의 (염화칼슘 배합 상향)]`
   - **우기 도로 수방 경보**: 시간당 강수량 및 누적강수 기반 `🌧️ 배수로 점검` / `🌊 집중호우·지하차도/사면 주의` / `🚨 극한호우·도로통제 검토`
6. **광주대구선(14번) 노선 미니맵 · Windy 실시간 위성/레이더 · 기상청 공식 HSR 레이더**
   - 8개 관심지역과 도로기상관측소를 연결한 인터랙티브 노선 미니맵과 Windy 임베드 위성·레이더 지도(`lat=35.47, lon=127.725`), 기상청 API허브 전국 레이더 HSR 합성영상을 함께 제공합니다.
7. **1:1 정방형(1080×1080) 브리핑 JPG 생성 및 공유**
   - 상단 `[📤 정방형 JPG 공유]` 클릭 시 **모아보기 종합 상황판(8개 지역)** 또는 **개별 지역 상세 브리핑**을 `1080×1080` 고해상도 JPG로 즉시 생성하여 파일 저장·클립보드 복사·모바일 메신저 공유(Web Share API)를 지원합니다.
8. **상시 감시 설정 메뉴 (`[⚙ 설정]`)**
   - 전체화면 감시 모드(Fullscreen), 특보 변동 차임벨 알림 소리(Web Audio 합성음 + 테스트), 화면 계속 켜두기(Screen Wake Lock + 탭 복귀 자동 재획득), 위험 지역 상단 우선 정렬, 야간 다크 모드, 동절기 대설·결빙 시안 훈련모드를 제공합니다.

## 3. 비밀환경변수(Secrets) 설정 안내 (API 키 보호 원칙)

> **보안 원칙**: 기상청 API 키는 소스 코드, HTML, 브라우저 `localStorage`, Git 저장소에 절대 포함하지 않으며 **서버 환경변수(Secrets)** 에만 등록합니다. 기상청 API허브(`apihub.kma.go.kr`) 통합 인증키 1개를 `KMA_SERVICE_KEY`에 입력하면 단기예보·도로기상관측(14번 노선)·레이더(HSR)·특보 조회에 모두 자동 적용됩니다.

| 환경변수 이름 | 필수 여부 | 설명 |
| :--- | :--- | :--- |
| `KMA_SERVICE_KEY` | **필수** | 기상청 API허브(`apihub.kma.go.kr`) 인증키 또는 공공데이터포털 단기예보 서비스키 |
| `KMA_RADAR_KEY` | 선택 | 기상청 API허브 레이더 HSR 인증키 (미입력 시 `KMA_SERVICE_KEY` 자동 공용 사용) |
| `KMA_ROAD_KEY` | 선택 | 기상청 API허브 도로기상관측 인증키 (미입력 시 `KMA_SERVICE_KEY` 자동 공용 사용) |
| `ROAD_LINE_CODE` | 선택 | 고속도로 노선 코드 (기본값: `14` = 무안광주대구선) |

### A. Render 배포 시 비밀환경변수 등록 방법
1. [Render Dashboard](https://dashboard.render.com/)에서 **New + > Web Service** (또는 **Blueprint**)를 선택하고 GitHub 저장소를 연결합니다 (`render.yaml`이 자동 인식됩니다).
2. **Environment** 탭(또는 생성 화면의 **Environment Variables**)에서:
   - `Key`: `KMA_SERVICE_KEY` / `Value`: 발급받은 기상청 API 키 입력
   - (선택) `ROAD_LINE_CODE`: `14`
3. **Save Changes** 클릭 후 자동 배포가 완료되면 발급된 `https://<서비스명>.onrender.com` 주소로 접속합니다.

### B. Railway 배포 시 비밀환경변수 등록 방법
1. [Railway](https://railway.app/)에서 **New Project > Deploy from GitHub repo**로 저장소를 연결합니다 (`railway.json` 자동 인식).
2. 서비스 클릭 후 **Variables** 탭에서 **+ New Variable**을 눌러 `KMA_SERVICE_KEY` 값을 입력합니다.
3. **Settings > Networking > Generate Domain**을 눌러 공개 HTTPS 주소를 발급받습니다.

### C. GitHub Pages + GitHub Actions Secrets 연동 방법
1. GitHub 저장소의 **Settings > Secrets and variables > Actions**로 이동합니다.
2. **New repository secret** 버튼을 눌러 `Name`에 `KMA_SERVICE_KEY`, `Secret`에 기상청 API 키를 입력하고 저장합니다.
3. GitHub Actions 워크플로(`.github/workflows/pages.yml`)가 서버 측에서 안전하게 기상청 데이터를 검증·스냅샷 생성(키 노출 0건)하여 공개 HTTPS 페이지로 배포합니다.

## 4. 로컬 실행 및 테스트

```bash
# 1. 환경변수 파일 생성 (.env는 .gitignore로 제외되어 커밋되지 않음)
cp .env.example .env
# .env 내 KMA_SERVICE_KEY= 뒤에 인증키 입력

# 2. 개발 서버 실행 (http://localhost:3000)
npm run dev

# 3. 단위 테스트 및 보안 검증 실행
npm test
```
